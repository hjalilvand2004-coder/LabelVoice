# برچسب‌خوان هوشمند دارو و محصولات (LabelVoice)

ابزار خواندن برچسب بسته‌بندی دارو و محصولات: از تصویر بسته، فقط متنِ **واقعاً قابل خواندن** را استخراج می‌کند و همان را به فارسی نمایش و می‌خواند.

> **محدوده محصول:** این ابزار فقط می‌گوید «روی بسته چه نوشته شده است»؛ نه سامانه تشخیص دارو است، نه تجویز، نه تعیین مقدار مصرف، نه توصیه پزشکی. اطلاعات غایب از اینترنت، حافظه مدل یا شناخت نام محصول تکمیل نمی‌شود.

## جریان پردازش

```
دوربین / بارگذاری تصویر
      ↓
اعتبارسنجی فایل (نوع واقعی، اندازه، پیکسل) + اصلاح EXIF
      ↓
ارزیابی کیفیت (تاری، نور، انعکاس) + راهنمای عملی فارسی
      ↓
OpenCV: برش دستی، صاف‌کردن چرخش، CLAHE، چند نسخه پردازشی
      ↓
OCR قابل تعویض: Tesseract (fas+eng) یا EasyOCR (fa+en)
      ↓
نرمال‌سازی نویسه‌ای + استخراج فیلدهای ساختاریافته با شواهد
      ↓
کنترل تناقض/ابهام + پاسخ فارسی قالبیِ وفادار به شواهد (+ LLM اختیاری خاموش)
      ↓
TTS فارسی (edge-tts با gTTS جایگزین؛ فقط با رضایت کاربر)
      ↓
رابط Streamlit راست‌به‌چپ: کادر OCR، جدول فیلدها، اصلاح دستی، JSON، صوت
```

## نسخه موبایل و قابل حمل (بدون پایتون!)

نسخه‌ای کامل از این محصول در پوشه **`mobile-app/`** قرار دارد که **بدون پایتون، بدون پای‌چارم، بدون نصب هیچ وابستگی‌ای** روی هر سیستم و هر گوشی اجرا می‌شود — فقط یک مرورگر مدرن لازم است:

- **ویندوز:** دابل‌کلیک روی `mobile-app/شروع-در-ویندوز.bat` (سرور محلی با PowerShell؛ بدون دسترسی مدیریتی) یا مستقیم `index.html` را باز کنید.
- **موبایل (اندروید/iOS):** پوشه را روی یک میزبان HTTPS (مثل GitHub Pages) بگذارید و «افزودن به صفحه اصلی» بزنید — به‌صورت اپ (PWA) نصب و آفلاین اجرا می‌شود؛ از v1.2.0 دکمه «دوربین زنده و خواندن جعبه» دارد (getUserMedia + تشخیص خودکار جعبه) و از v1.3.0 راهنماهای مودالی با معرفی فناوری هر بخش دارد (دکمه «؟»). **اندروید ۷ به بالا؟** APK آماده را از Releases نصب کنید (`LabelVoice-Android-1.3.1.apk`).
- **تک‌فایل قابل اشتراک:** `mobile-app/label-reader-singlefile.html` — همه چیز در یک فایل HTML.
- کل منطق ایمنی (نگهبان، شواهد، پاسخ قالبی) عیناً از پایتون به جاوااسکریپت منتقل و با ۴۸ آزمون و تست E2E مرورگر راستی‌آزمایی شده است. جزئیات: `mobile-app/README-MOBILE-fa.md`

## راه‌اندازی سریع

```bash
# 1) Python 3.11+ و محیط مجازی
python3 -m venv .venv && source .venv/bin/activate

# 2) وابستگی‌های اصلی
pip install -r requirements.txt

# 3) موتور OCR سیستم
#    Ubuntu/Debian:  sudo apt install tesseract-ocr
#    macOS:          brew install tesseract
#    Windows:        نصب‌کننده UB-Mannheim (راهنمای کامل: docs/INSTALL.md)

# 4) داده زبان فارسی (اگر models/tessdata موجود نیست)
python scripts/download_tessdata.py

# 5) اجرا
streamlit run app.py
```

نصب اختیاری EasyOCR (سنگین — حدود ۲۰۰ مگابایت PyTorch + مدل‌ها):

```bash
pip install -r requirements-easyocr.txt
```

## اجرا و آزمون

```bash
# رابط کاربری
streamlit run app.py

# خط فرمان روی یک تصویر
python scripts/run_demo_cli.py sample_images/en_paracetamol_500mg.png

# آزمون‌ها
pip install -r requirements-dev.txt
python -m pytest tests/ -q

# تولید مجدد تصاویر نمونه و سنجش دقت واقعی
python scripts/make_sample_images.py
python scripts/evaluate.py
```

## خروجی‌ها

- **پاسخ فارسی قالبی**: فقط از فیلدهای دارای شواهد؛ نمونه:

  > نام درج‌شده روی بسته: Paracetamol. قدرت درج‌شده: ۵۰۰ میلی‌گرم. تعداد درج‌شده: ۲۰ قرص. این اطلاعات از متن قابل خواندن بسته استخراج شده‌اند و توصیه پزشکی یا تعیین مقدار مصرف نیستند.

- **جدول فیلدها** با وضعیت (استخراج‌شده / نامطمئن / غایب / متناقض / اصلاح کاربر)، امتیاز اطمینان و شناسه شواهد OCR.
- **خروجی JSON کامل** شامل قطعات OCR، مختصات، سطرها، فیلدها، هشدارها و فراداده.
- **فایل صوتی mp3** از همان پاسخ تأییدشده (فقط با رضایت صریح برای ارسال به سرویس ابری و دانلود صریح کاربر).

## حریم خصوصی و ایمنی

- پردازش تصویر و متن **کاملاً محلی** است؛ تصویر/متن در لاگ یا فایل ذخیره نمی‌شود.
- ارسال متن به سرویس ابری فقط برای TTS و فقط با چک‌باکس رضایت صریح انجام می‌شود.
- کلیدهای API فقط از متغیر محیط (`LBR_*` یا `.env`) خوانده می‌شوند (نمونه: `.env.example`).
- محتوای OCR «غیرقابل اعتماد» است: هیچ دستور یا کدی از آن اجرا نمی‌شود و آزمون امنیتی دارد (tests/test_security.py).
- سرویس به‌صورت پیش‌فرض فقط روی `127.0.0.1` ارائه می‌شود.
- یادآوری: ممکن است نام بیمار یا اطلاعات شخصی روی بسته در تصویر باشد.
